# Experiment Artifacts

Each run is stored under `workspace/runs/run_<timestamp>/`.

Per run:
- `run_manifest.json`
- `final_summary.md`
- `preflight_check.json`
- `preflight_check.md`

Per iteration:
- `benchmark_result.json`
- `benchmark.stdout.txt`
- `benchmark.stderr.txt`
- `profile_report.txt`
- `profile_summary.txt`
- `profile_details.txt`
- `profile.stdout.txt`
- `profile.stderr.txt`
- `optimization_proposal.md`
- `iteration_summary.md`
